# Changelog

- 1.0.101 (Nov 6, 2026): On macOS the check that an edited script was run reads Windows-style file paths correctly, and the tests pass there again.
- 1.0.100 (Nov 6, 2026): The whole setup is rebuilt from shared parts so it breaks less, a new /untangle-codebase command does the same for your own projects, and a security pass closes holes: the OpenCLI read-only check can no longer be talked around, a claude.exe placed in a project folder is never run or handed to Nimbalyst, Git runs without a shell, and updates never drop to plain http. The chat and usage reports now cover 14 days, project settings in settings.local.json and parent folders count, extension installs stop with a clear message when Nimbalyst is missing, helpers handle background jobs and finished-job notices better, question forms are repaired instead of refused, and the homepage has a new film.
- 1.0.99 (Nov 6, 2026): The usage dashboard shows plan use and token use by plan week (this week, last week, the weeks before) with this computer's part of each, opens as a full panel from the Usage icon in Nimbalyst, and builds in seconds instead of half a minute.
- 1.0.98 (Nov 5, 2026): The review-gate test builds file names the way the hook does, so it passes on macOS too (1.0.97's fix was not enough).
- 1.0.97 (Nov 5, 2026): The tests pass on macOS again (one review-gate test assumed Windows file names).
- 1.0.96 (Nov 5, 2026): An update moves Nimbalyst to the Ink Cobalt theme once if you were on another one, sign-ins open a real browser window you can see, a new /design-system skill keeps a project's look in one DESIGN.md, and the rules ask you for a file or link when you could hand it over faster. Small rule edits no longer need a reviewer, and the plan logger checks every 30 seconds once you pass 70% of your week.
- 1.0.95 (Nov 5, 2026): Tests now pass on a fresh machine and on macOS, and on a Mac a big file you name in a message gets its one read, a hook crash is logged, and links and forms know which project a file is in.
- 1.0.94 (Nov 5, 2026): The systems map's hand-edit check no longer flags a script's own rerun that came in through a merged branch, and it names a listed script that has no commit yet.
- 1.0.93 (Nov 5, 2026): A file a script writes is listed in the project's systems map: a hand edit of it is refused with the script to change instead, and the map's check names one already edited by hand, so the next run can't bring old text back.
- 1.0.92 (Nov 5, 2026): Nimbalyst's chats now run your own Claude Code instead of the copy Nimbalyst bundles, so they get Claude Code fixes the day they ship rather than days later with a Nimbalyst release.
- 1.0.91 (Nov 5, 2026): Claude no longer stops after one finished step when you asked for the whole job, catches a reply that says a helper is running when none is, notes each helper's model, explains every shell command in a short capitalised line, and shows a project's next-release notes when a session starts.
- 1.0.90 (Nov 5, 2026): Every button in the Nimbalyst side bar has a short name under its icon, the extensions' too; the theme menu stays open while you try themes; a question form missing a box to type in gets one added instead of showing up twice.
- 1.0.89 (Nov 5, 2026): A Systems map panel in Nimbalyst shows your project's parts and links and marks the links whose code changed; Board Tidy archives finished sessions by itself; the Usage Plan pop-up is easier to read; Read Aloud shows one play strip per reply instead of one per paragraph; Commands asks before starting the same command twice; the Ink themes are refreshed.
- 1.0.88 (Nov 5, 2026): Updating Claude Code from inside a Nimbalyst session works: Nimbalyst's own no-update setting no longer blocks the setup's update step.
- 1.0.87 (Nov 5, 2026): Fewer wasted tokens: helpers run in the foreground unless they really run beside other work, a helper near its context limit finishes and reports instead of compacting, the installer and /update-setup keep Claude Code itself up to date, notes from the Note button or /btw interrupt a busy session only where it matters, and the usage report shows where wake-ups and big helpers spend.
- 1.0.86 (Nov 5, 2026): Replies arrive in one piece: while background jobs still run, a finished job no longer gets its own small status update, and you get one complete answer when everything is done.
- 1.0.85 (Nov 4, 2026): The update reminder now says how many releases you are behind and what they bring, so an update you skipped for weeks shows what you are missing. A short reply for you to type back is no longer taken for a shell command, and a starting planner says how long a plan takes.
- 1.0.84 (Nov 3, 2026): The "background task settled" prompt for work already reported now gets a short plain status reply instead of being refused, so Nimbalyst no longer shows a raw warning where the reply should be.
- 1.0.83 (Nov 3, 2026): Fewer wasted turns after background jobs: the "background task settled" prompt is refused when the work was already reported, and helpers now run in the foreground unless a step really runs beside another. A session that just finished a job is told to start the next one fresh, a helper that has grown large is told to finish and report, and the usage report counts these.
- 1.0.82 (Nov 3, 2026): The review-gate fix of 1.0.81 now also works where the temp folder has two names (macOS, short Windows paths).
- 1.0.81 (Nov 3, 2026): The review gate no longer asks for a review of files another open session edited, so running several sessions at once stops costing a reviewer for work this one never touched.
- 1.0.80 (Nov 3, 2026): A procedure done a third time now becomes a skill with one line in the project's CLAUDE.md saying when to call it, and a new hook reminds the agent to add that line whenever a skill is written.
- 1.0.79 (Nov 3, 2026): The rules file is about a quarter shorter, Nimbalyst-only notes now load only in Nimbalyst, and a helper job over 50 tool calls is refused and has to be split.
- 1.0.78 (Nov 2, 2026): Voice typing now tells you to pick Whisper Large v3 Turbo in Handy, which transcribes more accurately at about the same speed and handles Russian as well as English.
- 1.0.77 (Nov 2, 2026): Long reading now goes to Claude's own capped Sonnet helpers instead of outside workers that often failed, and an update removes those workers and the Antigravity hook they needed; the planner writes the job list with each step's helper, the reviewer names what triggers each Important finding, and blind-review is now blind-screen-review, for screens only.
- 1.0.76 (Nov 2, 2026): /court is gone and an update removes it, a hook that crashes now leaves a trace and the next session tells you, and the rules file is a little shorter.
- 1.0.75 (Nov 2, 2026): Code edited with no build or test after it now stops the session once, a big change is reviewed before a push, one /setup-audit replaces the five audit skills and can show how your questions and reviews really went, the rules are shorter, hooks that watch your wording now hear Russian too, an update moves a Sonnet install to Opus medium with a one-line undo, the installer checks Git Bash and Node, and the free worker reads a .env file only when you ask for it.
- 1.0.74 (Nov 2, 2026): A build or design request now goes to a planner first in every project, however loosely it's worded, a helper cut off at its limit no longer counts as finished, the review gate closes its gaps and keeps work due across a question, the free worker can't reach your login or the web, new installs start on Opus at medium effort and keep logs 120 days, and the phone bot, shared usage and read-aloud are now add-ons.
- 1.0.73 (Nov 2, 2026): Workers start lean and take the project's rules from their brief, every recommended option gets a second look before you see it, one reviewer runs by itself on bigger changes, a systems map tells helpers what their work connects to, and on Windows /pc-tidy and a new Commands button show what is holding the computer's memory and stop what finished sessions left behind, with a reminder to restart Nimbalyst after 12 hours open.
