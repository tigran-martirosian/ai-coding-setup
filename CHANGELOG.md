# Changelog

- 1.0.60 (Oct 29, 2026): A long session now compacts itself while its cache is warm, with a focus line that keeps your own messages, open asks and the next step, and moves to a fresh session only after an hour idle. After a handoff, a message you type in the old session and the reports of its helper sessions are forwarded to the new one, and the brief no longer copies those reports. The Commands extension gets a **Note** button next to Send that reaches a busy chat. A link to a file outside the open project is now written as a path in code, since Nimbalyst cannot open it. A new `blind-review` skill has reviewers who see only screenshots rank the flaws of a page or design before you call it done, `/chat-review` ranks eight kinds of incidents with quotes, and the rules gain a list-first reply to a message with several asks, a model and effort ladder, one rerun before a failure is real, and a known-failures list.
- 1.0.59 (Oct 27, 2026): Web research moves off the free Gemini worker, which over 30 days answered only 43 of the 72 questions it was asked and took nearly four minutes to do it. A version or "is X released" question is now a one-second lookup from the place that knows it (`workers/versions.mjs`: endoflife.date, GitHub releases, npm, PyPI, crates, Docker Hub, Maven, NuGet), a list of things from one site comes from that site's own catalogue, and two new checks hold a reply back when it claims something may not be available without having checked, or lists fewer things than you asked for. A status question is also answered by the one call that answers it instead of a full diff or dry run, and a new check stops a command that will run for minutes from piping its output straight into `head` or `tail`, where cutting off the wrong part means running the whole thing again. A fresh install that answers no to both outside workers no longer stops with an error. The usage dashboard also survives a plan change, and file links and question forms got the fixes from the last review.
- 1.0.58 (Oct 26, 2026): Two new checks before a reply ends: `file-link-gate` sends back file links that Nimbalyst's chat can't open, and `code-review-gate` asks for a `/code-review` after a turn that changed three or more code files. `question-other` also refuses a question with no box to type your own answer and a "look at this" question with no link, `command-explain` adds a stand-in line to a command that has none instead of refusing it, `worker-nudge` refuses uncapped helper types every time, an Antigravity answer that runs out of time is kept as a partial answer, and the rules ask for every question you typed to be answered first.
- 1.0.57 (Oct 16, 2026): A bigger code change gets a `/code-review` before Claude calls it done, the lead skill's reviewer runs on Opus and tags each finding Important, Nit or Pre-existing, small clear jobs with a check go to a Sonnet helper, and repeat-guard now watches a helper's own steps instead of the main session's.
