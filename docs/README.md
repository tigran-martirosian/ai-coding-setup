# Docs

The files in this folder, by who they're for. The [README](../README.md) one folder up is the place to start.

## If you're new to the setup

- [HOW-TO.md](HOW-TO.md): what each part is for, what to type and what you should see.
- [features.md](features.md): the parts the README only names, in detail (agents, hooks, sessions, usage, backup, rules).
- [setup.md](setup.md): how the author works with coding agents, and where this setup fits in that.

## If you're installing it

- [full-install.md](full-install.md): the install steps, written for Claude to carry out on a new Windows computer or Mac. You start it with the one command in the README.
- [features.md#install-details](features.md#install-details) and [features.md#updating-details](features.md#updating-details): what the installer and the updater change.

## If you want to know how well it works

- [test-results.md](test-results.md): how the reviewer agent and the hooks were tested, and what the numbers were.

## If you work on the setup

- [img/](img): the pictures, clips and video the README and features.md show. The clips and the video are made by `promo/`.
- The tests are in `tests/` and run with `node tests/run-all.mjs`; the README's Tests section says what they cover.
